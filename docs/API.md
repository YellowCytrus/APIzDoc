# API PIZDo — Markdown to PDF (Typst)

Документация REST API сервиса конвертации Markdown в PDF с настраиваемыми стилевыми профилями.

- **Базовый URL:** `http://localhost:8000` (при запуске через Docker)
- **Авторизация:** не используется (MVP)
- **Формат:** JSON для тел запросов/ответов, кроме генерации PDF (multipart/form-data → binary PDF)

Интерактивная документация: [Swagger UI](/docs), [ReDoc](/redoc).

---

## Коды ответов и ошибки

| Код | Описание |
|-----|----------|
| 200 | OK, тело — JSON или PDF |
| 204 | No Content (успешное удаление) |
| 400 | Неверный запрос (пустой файл, невалидные поля) |
| 404 | Ресурс не найден (профиль, элемент стилей) |
| 500 | Ошибка конвертации (Pandoc или Typst) |

Тело ошибки: `{"detail": "строка или объект"}`.

## Профили (Profiles)

Профиль — именованный набор стилей элементов. У одного профиля может быть не более одного набора стилей на каждый тип элемента.

### POST /profiles

Создать профиль.

**Тело запроса:**

```json
{
  "name": "GOST default"
}
```

| Поле  | Тип   | Обязательное | Описание        |
|-------|--------|--------------|-----------------|
| name  | string | да          | 1–255 символов, уникальное |

**Ответ:** 200, объект профиля.

```json
{
  "id": 1,
  "name": "GOST default"
}
```

---

### GET /profiles

Список профилей с пагинацией.

**Query-параметры:**

| Параметр | Тип | По умолчанию | Описание        |
|----------|-----|--------------|-----------------|
| limit    | int | 50           | 1–200, макс. записей |
| offset   | int | 0            | Смещение        |

**Ответ:** 200, массив профилей.

```json
[
  { "id": 1, "name": "GOST default" },
  { "id": 2, "name": "Compact" }
]
```

---

### GET /profiles/{profile_id}

Получить один профиль по ID.

**Ответ:** 200 — объект профиля; 404 — профиль не найден.

---

### PATCH /profiles/{profile_id}

Частичное обновление профиля (только переданные поля).

**Тело запроса:**

```json
{
  "name": "New name"
}
```

Все поля опциональны. Ответ: 200 — обновлённый профиль; 404 — профиль не найден.

---

### DELETE /profiles/{profile_id}

Удалить профиль и все связанные стили элементов.

**Ответ:** 204 без тела; 404 — профиль не найден.

## Стили элементов (Element styles)

Для каждого профиля можно задать стили по типам элементов. Путь для каждого типа:

`/profiles/{profile_id}/{element_type}`

Типы элементов: `bullet_list`, `document`, `figure`, `footnote`, `heading`, `numbered_list`, `par`, `quote`, `table`.

| Метод | Описание |
|-------|----------|
| **POST** | Создать или полностью заменить стили элемента (create-or-replace). |
| **GET** | Получить текущие стили. 404, если стили для этого элемента ещё не заданы. |
| **PATCH** | Частичное обновление (только переданные поля). 404, если стили не заданы. |
| **PUT** | Полная замена стилей (аналог POST). |

Тела запросов — JSON. Ответы — JSON с текущим состоянием стилей после операции.

### bullet_list — маркированный список

**POST /profiles/{profile_id}/bullet_list**

```json
{
  "tight": true,
  "marker": ["- ", "‣", "–"],
  "indent": 0.0,
  "body_indent": 0.5,
  "spacing": "auto"
}
```

| Поле        | Тип    | По умолчанию | Описание                    |
|-------------|--------|--------------|-----------------------------|
| tight       | bool   | true         | Компактный список           |
| marker      | [str]  | ["- ", "‣", "–"] | 1–3 маркера по уровням |
| indent      | float  | 0.0          | Отступ, pt (≥ 0)            |
| body_indent | float  | 0.5          | Отступ тела, em (≥ 0)       |
| spacing     | string | "auto"       | "auto" \| "tight" \| "loose" |

**PATCH:** все поля опциональны.

## Генерация PDF

### POST /profiles/{profile_id}/generate-pdf

Конвертировать загруженный Markdown-файл в PDF, применив стили выбранного профиля.

**Content-Type:** `multipart/form-data`

| Поле  | Тип  | Обязательное | Описание                    |
|-------|------|--------------|-----------------------------|
| file  | file | да           | Файл в формате Markdown    |

**Ответ:** 200 — бинарный PDF, заголовок `Content-Disposition: attachment; filename="…"` (имя файла берётся из загруженного, расширение заменяется на `.pdf`).

**Ошибки:**

- 400 — пустой файл
- 404 — профиль не найден
- 500 — ошибка Pandoc или компиляции Typst (в `detail` краткое описание)

## Пример сценария

1. Создать профиль: `POST /profiles` с `{"name": "Мой профиль"}`.
2. Задать стили списка: `POST /profiles/1/bullet_list` с нужными полями (или пустой объект `{}` для значений по умолчанию).
3. При необходимости задать другие элементы: `document`, `par`, `heading` и т.д.
4. Сгенерировать PDF: `POST /profiles/1/generate-pdf`, в форме указать поле `file` с Markdown-файлом.
5. В ответе получить PDF и сохранить или открыть в браузере.
