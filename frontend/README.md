# PIZDo Frontend — Markdown to PDF Editor

Vue3 + Vite + TypeScript frontend for the PIZDo Typst Markdown → PDF editor.

## Run

```bash
# Install dependencies
npm install

# Development (requires backend at http://localhost:8000)
npm run dev

# Build
npm run build
```

## Environment

- `VITE_API_URL` — Backend API base URL (default: `http://localhost:8000`)
